# Jesper Tng - Professional Portfolio Website

A modern, responsive portfolio website showcasing Jesper Tng's expertise as a Product Manager for Digital Transformation.

## Overview

This portfolio website features a clean, professional design with smooth animations and interactive elements. Built with vanilla HTML, CSS, and JavaScript, it provides an engaging user experience across all devices.

## Features

- **Responsive Design**: Fully responsive layout that works seamlessly on desktop, tablet, and mobile devices
- **Modern UI/UX**: Clean, minimalist design with professional color scheme and typography
- **Smooth Animations**: Scroll-based reveal animations and smooth transitions throughout
- **Interactive Elements**: Hover effects, smooth scrolling navigation, and dynamic content
- **Mobile-Friendly Navigation**: Hamburger menu for mobile devices with smooth toggle animations
- **Performance Optimized**: Lightweight codebase with optimized assets and efficient animations

## Sections

1. **Hero Section**: Eye-catching introduction with call-to-action buttons
2. **About**: Overview of professional background and core competencies
3. **Experience**: Showcase of key projects and achievements in digital transformation
4. **Skills**: Comprehensive list of technical and professional skills
5. **Contact**: Multiple ways to connect and get in touch

## Technology Stack

- **HTML5**: Semantic markup for better accessibility and SEO
- **CSS3**: Modern styling with CSS Grid, Flexbox, and custom properties
- **JavaScript (ES6+)**: Interactive features and animations
- **Google Fonts**: Inter font family for clean, modern typography

## Customization

### Updating Content

1. **Personal Information**: Edit the text content in `index.html`
2. **Projects/Experience**: Modify the experience cards in the Experience section
3. **Skills**: Update the skills tags in the Skills section
4. **Contact Information**: Update email and social media links in the Contact section

### Styling

- **Colors**: Update CSS custom properties in `styles.css` (`:root` section)
- **Typography**: Change font families in the CSS file
- **Layout**: Adjust grid and flexbox properties for different layouts

### Features

- **Animations**: Enable/disable features in `script.js`
- **Typing Effect**: Uncomment the typing effect code at the bottom of `script.js`

## Getting Started

### Local Development

1. Clone this repository
2. Open `index.html` in your web browser
3. No build process required - just open and view!

### Deployment

This website can be deployed to any static hosting service:

- **GitHub Pages**: Push to GitHub and enable GitHub Pages in repository settings
- **Netlify**: Drag and drop the folder or connect your repository
- **Vercel**: Import the repository and deploy
- **Any web server**: Upload files to your web hosting service
